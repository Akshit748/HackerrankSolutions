# HackerRank Solutions – C, Python, and SQL

This repository documents my problem-solving progress in **C, Python, and SQL** during and after high school.  
It serves as a consolidated archive of solutions solved on **HackerRank**, organized by language and learning stage.

The primary goal of this repository is to demonstrate **consistent practice, foundational understanding, and progression over time**, it is **NOT** a showcase of **Optimal or Competitive Solutions**.

---


###  Python
- Studied Python for **2 years in high school** as part of formal coursework.
- Problems are primarily **elementary to beginner-level**, including:
  - Input/output handling
  - Conditional statements and loops
  - Lists, strings, tuples, and dictionaries
  - Basic error handling
- Also includes a smaller set of **post–high school problems**, such as:
  - Pattern generation
  - Mathematical and trigonometric problems
  - More detailed operations on data types
  - Basic usage of standard Python modules

These solutions reflect **foundational learning and early problem-solving exposure**.

---

###  C
- Studied **C from scratch** during my **first semester of university**.
- Problems are based on university coursework, with added depth through practice.
- Topics covered include:
  - Functions and control flow
  - Arrays and strings
  - Pointers and pointer arithmetic
  - Structures
- Most problems fall in the **easy to medium difficulty** range.

This section represents my transition from high-level languages to **low-level programming**.

---

###  SQL
- Studied SQL briefly during high school.
- The repository contains a **single consolidated file (megathread)** of SQL queries.
- Covers:
  - Basic `SELECT` queries
  - Filtering and sorting
  - Aggregate functions
  - Simple joins and subqueries
